# jarvisd event protocol

Version 2. Generated by `python -m jarvis.protocol` from `service/jarvis/protocol.py`; do not edit by hand.

jarvisd pushes one JSON object per line over `$XDG_RUNTIME_DIR/jarvis-workos/jarvisd.sock` to clients that sent `{"op": "subscribe"}`. Every event has `event` and `ts`; the fields below are always present. Requests are `{"op": …, "id": n}` and get `{"reply": n, "ok": …}`.

| Event | Always has | Meaning |
|---|---|---|
| `status` | `status` str | The one status every companion animates: idle, listening, transcribing, thinking, working, speaking, approval, dictating, connecting, muted, paused, error. |
| `voice` | `mode` str, `phase` str, `mic_open` bool, `muted` bool | Voice controller state (mode wake/conversation/dictation/paused, engine, model, devices…). |
| `level` | `source` str, `value` int/float | Live audio level 0..1 of the microphone (source mic) or of Jarvis's own voice (out), ~15 Hz while audible; `bands` = real FFT bands 0..1 when present. |
| `vad` | `speaking` bool, `engine` str | Pipecat's VAD / turn detection: the user started or stopped talking in a conversation (once per change). |
| `barge` | `engine` str | The user interrupted Jarvis; queued speech was dropped (clear_ms). |
| `wake` | `score` int/float | The wake word fired. |
| `mic` | `state` str | Microphone capture recovered after a failure. |
| `transcript` | `role` str, `text` str, `final` bool | Live captions: role user/assistant; partials update in place until final. |
| `reply` | `text` str | A complete answer (task_id when it belongs to a task). |
| `task` | `task` dict | A task changed: {id, title, state, steps[], result, error, elapsed_ms…}. |
| `approval` | `approval` dict | Something needs a yes/no: {id, kind (jarvis|agent), tool, risk, summary, args, created, origin, desk_only}. Surfaces showing it answer op approval_seen. |
| `approval_resolved` | `id` str, `allowed` bool, `reason` str | An approval was answered, timed out, was withdrawn or was never shown. |
| `dictation` | `state` str | Dictation: recording, transcribing, inserted, cancelled, error… |
| `pipeline` | `engine` str, `state` str | A Pipecat conversation pipeline: connecting, connected, reconnecting, fallback, error, closed; tts_fallback / tts_restored (tts: the voice now speaking). |
| `tool_call` | `state` str | A model function call started / finished inside a conversation. |
| `live` | `state` str | Gemini Live connection: connected (model, connect_ms) or unavailable (error). |
| `screen` | `state` str | Screen sharing into a Live conversation: sharing, frame, stopped. |
| `metrics` | `engine` str | Latency figures (first_audio_ms: end of speech to first audio). |
| `settings` | `settings` dict, `ui` dict, `lang` str | Settings changed; UI labels in the language. |
| `hud` | `card` dict | A rich result card: {id, kind, title, data, ttl}. |
| `notice` | `notice` dict | A proactive suggestion: {id, kind, title, body, actions[]}. |
| `reminder` | `reminder` dict | A timer or reminder was set, fired or cancelled: {id, kind timer|reminder, text, due, state pending|fired|cancelled}. |
| `meeting` | `state` str | Meeting notes: recording, processing, idle. |
| `focus` | `active` bool | Focus mode on (until, minutes) or off. |
| `control` | `until` int/float | Keyboard/mouse control granted until (epoch s; 0 = none). |
| `health` | `service` str | A capability's health check result. |
| `integrations` | `status` dict | Connected apps status. |
| `gateway` | `status` dict | Messaging gateway status. |
| `call` | `call` dict | A phone/WhatsApp call: {call_id, state ringing|connecting|connected|ended…}. |
| `workspace` | `opened` bool | The Living Workspace was opened. |
| `agents` | `sessions` list | Coding agent sessions on this desktop (Claude Code, Codex): [{id, agent, label, project, cwd, state, activity, prompt, summary, updated…}]; state is idle, thinking, working, permission, question, waiting, done or error. |
| `backends` | `status` dict | OpenClaw and Hermes: {openclaw: {state, healthy, version, error, manage…}, hermes: {…}, lockdown} (lockdown: Stop all is in effect). |
| `catalog` | `summary` dict | The capability registry changed: {total, usable, duplicates, by_provider, refreshed}. |
| `research` | `status` dict | Web research services: {enabled, ready, engine: {state, healthy, model, model_ready, version, morphic…}, searxng: {state, healthy, url…}, active, stats}. Answers themselves arrive as hud cards of kind research (run_id, query, mode, state, phase, sources[], answer, citations[], blocks[], verification, conflicts, metrics). |
| `accounts` | `status` dict | Accounts & Integrations: {vault {backend keyring|file|none, encrypted, problem}, cards [{id, label, group, kind account|local, auth oauth|qr|form|none, official, experimental, cost, can[], cannot[], limitations[], capabilities [{id, label, kind, state verified|granted|missing_permission|unavailable|unsupported|error}], state (not_configured, ready, awaiting_user, verifying, connected, needs_attention, expired, reconnecting, unsupported, failed), action, accounts [{id, label, state, capabilities, error {code, title, body, actions[], details}}], setup[], setup_fields[]}], flows[]}. |
| `auth` | `flow` dict | One sign-in in progress: {id, connector, step starting|qr|qr_expired|browser|form|verifying|done|error|cancelled, message, qr {size, rows[] of '0'/'1'} (modules only, never the payload), qr_expires, url, fields [{name, label, kind}], error, identity {label}}. |
| `onboarding` | `state` dict | First-run setup: {stage welcome|language|personal|connect|verify|ready|done, index, open, name, mode, voice, language, ui_lang, suggestions [{label, ask, available}]}. |
| `backup` | `status` dict | Backups: {location, schedule, last {path, created, verified, reauth[]}, running, backups[]}. |
| `jobs` | `jobs` list, `summary` dict | Background agents (jobs.Scheduler): [{id, kind, label, icon, title, state queued|waiting|running|paused|awaiting_approval|succeeded|failed|cancelled|interrupted, doing, progress {done,total} (the plan's real steps) or null, seat, target {app, window_id, title}, elapsed_s, attempts, error, result, files[], can_retry}]; summary {running, queued, paused, approval, failed, seats, halted}. At most ~4 events a second. |
| `guide` | `op` str, `run_id` str | On-screen guidance (navigate). op show: kind ring|ghost, rect {x,y,width,height} in Hyprland layout px, monitor, label, caption, step, total, mode guide|do|show, hold_s, task_id; op hide: for a capture, show again follows; op end: reason done|stopped|stuck|timeout|error, caption. |

## Requests the island and agents use

| op | Fields | Reply |
|---|---|---|
| `subscribe` | — | snapshot: status, voice, settings, ui, approvals, tasks, agents, history, protocol, activities {reminders (due within a day), focus, meeting} |
| `approve` | `approval_id`, `allow` | `ok` |
| `approval_seen` | `approval_id` | `ok`: a surface is showing it (agents wait ≤2 s for this) |
| `agent_hook` | `agent` (claude/codex), `event` (the hook's JSON) | PermissionRequest: `decision` allow/deny/null, `message`; others: `session` |
| `agents` | — | `sessions` |
| `activity` | `action` cancel_reminder (+ `reminder_id`), end_focus, stop_meeting or cancel_meeting | `task_id`: runs as a visible task, not awaited |
| `devices` | — | `inputs`, `outputs` [{name, label, default}], `input`, `output` (the voice.input_source / voice.output_target settings; setting one switches the open device at once) |
| `guide` | `action` next, stop or status | `active`, `step`, `label`, `caption`: the walkthrough on screen (navigate) |
| `learn` | `action` answer (+ `question` number, `choice` index: a tapped option), reveal, grade (+ `grade` again/hard/good/easy) or stop | the `learn` tool's result; the quiz or flashcard card updates by `hud` |
| `research` | `action` ask (+ `query`, `mode` auto/quick/adaptive/thorough, `fresh`), cancel, status, stats, open (+ `url`: a source of a recent answer), export (+ `run_id`, `kind` xlsx/docx/pdf/md), restart (+ `target` research/searxng), mcp (+ `agent`, `query`: the Hermes/OpenClaw bridge) | ask: `task_id` (the answer streams as a `hud` card of kind research); others: their result |
| `accounts` | `action` status (+ `query`: intent search, `refresh`), connect (+ `connector`, `options` {capabilities[], account_hint, method}), submit (+ `flow_id`, `values`), cancel / new_qr (+ `flow_id`), verify / disconnect (+ `account_id`), configure (+ `connector`, `values`), install (+ `connector`), vault | the result; progress arrives as `auth` and `accounts` events |
| `onboarding` | `action` status, set (+ `fields` {language, name, voice, mode, connect_later}), next, skip, back, goto (+ `stage`), finish, reset | `state` |
| `backup` | `action` status, create (+ `passphrase`, `categories`), preview / verify / restore (+ `path`, `passphrase`, `categories`) | the result (create also verifies the new archive) |
| `imports` | `action` status, preview / apply (+ `source` {id, path, label}), cancel | the result |
| `listen` / `stop_speaking` / `mute` / `ask` / `cancel` | see daemon.py | |
